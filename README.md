# AceX.in — E-Commerce Frontend

A modern, responsive electronics e-commerce frontend built with **HTML, CSS, and JavaScript**.

## ✨ Features

* Responsive modern UI
* Product search and category filtering
* Shopping cart functionality
* Wishlist system
* Product quick-view modal
* Deals section
* Responsive mobile navigation
* Interactive UI animations
* Clean dark-themed interface

## 🛠️ Tech Stack

* HTML5
* CSS3
* JavaScript
* SVG
* Responsive Design

## 📌 Project Scope

AceX.in is a **frontend-only e-commerce project** created to practice and demonstrate modern web development concepts.

There is currently **no backend, authentication, database, or real payment system**.

## 🚀 Running Locally

Clone the repository:

```bash
git clone https://github.com/Sayed-Ameen04/acex-ecommerce.git
```

Open the project folder and launch `index.html` in your browser.
